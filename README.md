# Real-Time Chat App

A **real‑time chat application** built with a modern JavaScript stack. The project includes a Node.js/Express backend and a vanilla‑CSS/Vite‑based frontend that communicates via WebSockets to provide instant messaging between users.

---

## 🚀 Features

- **Live messaging** with WebSocket (Socket.io) integration
- **Authentication** using JWT tokens (see `backend/src/controllers/auth.controller.js`)
- **Email notifications** for password resets and invites (`backend/src/emails/emailHandlers.js`)
- **Responsive UI** built with vanilla CSS and modern layout techniques
- **Dockerised development** (Dockerfile and `docker-compose.yml` included)
- **Extensible architecture** – clean separation of routes, controllers, and services

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/haseeb318/Real-Time-Chat-App.git
   cd Real-Time-Chat-App
   ```
2. **Install dependencies**
   ```bash
   # Backend
   cd backend && npm install && cd ..
   # Frontend
   cd frontend && npm install && cd ..
   ```
3. **Set up environment variables**
   Create a `.env` file in `backend/` with at least the following keys:
   ```env
   PORT=5000
   MONGODB_URI=mongodb://localhost:27017/chatapp
   JWT_SECRET=your_secret_key
   EMAIL_USER=you@example.com
   EMAIL_PASS=your_email_password
   ```
4. **Run the application**
   ```bash
   # In separate terminals
   cd backend && npm run dev   # Starts Express + Socket.io server
   cd frontend && npm run dev  # Starts Vite dev server
   ```
5. Open **http://localhost:3000** (or the port shown by Vite) in your browser.

## 🧭 Usage

- Register a new account or log in with existing credentials.
- Once authenticated, you are connected to the WebSocket server and can join chat rooms.
- Use the UI to send messages; they appear instantly for all participants.
- Password reset and invitation emails are sent automatically via the email handlers.
